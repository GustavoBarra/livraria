    Sobre a Livraria Página Viva

    Uma livraria feita para quem ama histórias

    A Livraria Página Viva é um projeto de página web desenvolvido para apresentar um livro em destaque, seus formatos disponíveis e informações de contato.

    O projeto utiliza HTML para estruturar o conteúdo, CSS para criar a apresentação visual e JavaScript para adicionar uma interação simples com o carrinho.

    A proposta é proporcionar uma navegação simples, organizada e agradável para o usuário.
